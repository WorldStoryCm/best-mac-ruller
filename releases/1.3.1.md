Fixes Attach selecting a different application behind the window you clicked.

- Window selection now follows macOS mouse hit-testing, including overlapping, floating, and click-through windows.
- Picking uses the original click coordinates before changing focus, so guide-unit rounding cannot change the selected window at an edge.
- Finishing Attach returns focus to the selected application. A failed new selection no longer hides its message behind the previous attachment label.

Verified with separate test applications, moving and overlapping windows, and two connected displays. Existing guides and preferences are preserved. macOS 13 or later; universal Apple Silicon and Intel build. This build is ad-hoc signed and is not Apple-notarized.
