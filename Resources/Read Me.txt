Ruller 1.3.2
A small screen alignment utility for macOS 13 or later.
This universal app supports both Apple Silicon and Intel Macs.

INSTALL
1. Unzip the download.
2. Drag Ruller.app into your Applications folder.
3. Open Ruller. Look for the floating controls and ruler icon in the menu bar.

FIRST OPEN
This build is locally signed, but is not notarized by Apple and has no Developer ID certificate.
If macOS blocks it, and you trust the copy your colleague sent, first try opening the app,
then go to System Settings > Privacy & Security > Open Anyway.
Apple's instructions: https://support.apple.com/en-gb/102445
On a managed work Mac, IT may need to approve it.

USE
Choose Vertical or Horizontal, then click to place a line.
Choose Line, then drag to draw an angled line.
Press Escape when done: you can now click, scroll, and switch windows underneath.
Your lines remain fixed on the screen.

MEASURE DISTANCES
Add two horizontal or two vertical guides. The distance between them appears automatically.
With more guides, each neighboring pair gets its own measurement.
Values update live as you drag or nudge, and stay visible in click-through mode.
Choose Screen pt or Device px for the units; on a 2x Retina screen, 0.5 pt = 1 px.
Distance uses the guide coordinates, independent of line thickness.
In Edit mode, drag a distance label to move the measurements without moving the guides.
Use the Distances checkbox to show/hide measurements separately from coordinate labels.
Gap measurements work with the Horizontal and Vertical tools; angled lines show their length.

MULTI-SELECTION AND WINDOW ATTACHMENT
In Edit lines, Shift-click guides or drag a rectangle from empty space to select several.
Command + A selects all visible guides on the current display. Drag or nudge them together.
Color, opacity, thickness, duplicate, delete, and undo apply to the selected guides.
Choose Attach..., then click a window. Its guides follow when you move it.
They hide with the window, detach when it closes, and can be detached manually.
Links last for this Ruller session; guide positions still save after quitting.

LOUPE AND CONTRAST
Control + Option + M toggles a pixel loupe. Choose 4x, 8x, or 16x zoom in the panel.
On first use, allow Ruller in macOS Screen Recording settings; restart if macOS asks.
Only the loupe reads screen pixels. No audio, image saving, or uploading is involved.
The loupe excludes Ruller's own windows and starts off after relaunch.
High contrast adds a black-and-white outline without moving the guide's measured position.

SHORTCUTS
Control + Option + P    Show / hide controls
Control + Option + R    Edit / click through
Control + Option + H    Show / hide lines
Control + Option + M    Show / hide loupe
Command + A            Select all visible guides on the current display
Escape                 Finish editing
Arrow keys             Move selected guides by one chosen unit
Shift + arrows         Move by ten units
Option + arrows        Move by one display backing pixel
Command + Z            Undo

Customize the four global shortcuts using the gear button or Keyboard Shortcuts in the menu.
Click a shortcut, then press your combination. Escape cancels; Restore defaults resets all four.

Hiding the controls finishes editing and keeps your guides visible.
Reopen the controls with Control + Option + P or from the menu-bar ruler icon.
Quit from that same menu.

Lines and settings are saved automatically on your own Mac.
Drawing and measuring work offline. No account is needed; Screen Recording permission is needed only for the optional loupe.
Screen pt roughly matches browser CSS pixels at 100% zoom; Device px uses macOS backing pixels.

UPDATES
Open the menu-bar ruler icon > Check for Updates...
Check Automatically enables or disables periodic checks. Installation requires your choice.
Updates are downloaded from GitHub and their signatures are checked before extraction.
Your saved lines stay on your Mac. Screen contents and guides are never uploaded.
If upgrading from 1.1.0 or earlier, quit Ruller and replace the app manually once.
Latest download: https://github.com/WorldStoryCm/best-mac-ruller/releases/latest
